# 潮汐之间

安装：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`；生产构建：`npm run build`。

空间音频逻辑测试（无需浏览器，使用 Web Audio mock）：`node scripts/test-spatial-audio.mjs`

生成船声演示素材：`node scripts/generate-sounds.mjs`（产物已提交在 `public/media/audio/`）。

Docker 启动：`docker compose up --build`，访问 http://localhost:8133 。

## 空间声音现场

钟声、船声、人物声、劳作声各自拥有**固定方位**（与屏幕热点同一套 yaw/pitch 球坐标）
与**有效时间窗**（与热点可见性一致的 `[start, end)`）。

- 基于 Web Audio `PannerNode`（HRTF），聆听者方位每帧与全景相机同步；
  转头改变方位，缩放改变距离响度，声音与屏幕热点位置始终对应。
- 手机浏览器首次需点击解锁音频（任意点击或声音状态条均可），解锁前不发声。
- 同时发声数量有上限（4），人物故事优先级最高；刚响起的声音有短时保护，
  连续转头不会被反复截断。
- 拖动进度条跨过声音起止点时，拖动过程不重排声部，以**落点**为准恢复；
  收藏回访遵循同一规则，返回主线后现场声从当前位置继续，绝不叠加第二份。
- 进入访谈时现场声压低为轻微环境声，人物讲话走独立总线（语音合成，
  不可用时回退程序化人声）保证清晰；返回后恢复原现场声。
- 耳机拔出、素材迟到/失败均有可见状态，并提供重试；界面响度指示与真实播放一致。
- 船声为真实网络素材（`fetch` + `decodeAudioData`），其余声源在解锁后程序化合成，
  两类素材共用同一套加载状态机。
